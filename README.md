# 💻 C Programming Practice

A collection of beginner-friendly C programs to strengthen your fundamentals in logic building, pattern creation, and simple algorithm implementation.

## 📁 What’s Inside

This repository includes C programs categorized by common programming problems such as:

### 🔢 Number & Math Programs
- `1_2_4_8_16...(n power of 2).c` – Print powers of 2 up to _n_
- `Fibonacci_series_till_=n.c` – Generate Fibonacci numbers up to _n_
- `Find_avarge_of_given_n_numbers.c` – Calculate average of _n_ numbers
- `Find_max.no.out_of_three_no.c` – Find maximum of 3 numbers
- `Multiplication_table_from_1_to_n.c` – Print multiplication tables

### 🔠 Alphabet & Star Pattern Programs
- `Alphabetical_solid_square.c`
- `Alphabetical_triangle_type_1.c`
- `Quadrilateral_star_pattern.c`

### 🔢 Number Patterns
- `0_&_1_triangle.c`
- `Number_triangle_type_1.c`
- `Rhs_triangle_1_2_3_series.c`

### 🧮 Basic Logic & Utility
- `Calc_using_switch_case.c` – Simple calculator using `switch`
- `Day by number.c` – Return weekday based on numeric input

## ✅ Who This Is For

- Beginners in C programming
- Students preparing for coding exams/interviews
- Anyone who wants to practice fundamental logic building
